## 4. Описание проделанной работы

### 4.1 Архитектура приложения

Приложение реализовано как одностраничное приложение Streamlit с навигацией по разделам через боковую панель.

#### Технологический стек

| Технология | Назначение |
|------------|------------|
| Streamlit | Веб-фреймворк для создания интерактивных приложений |
| Pandas | Обработка и анализ данных |
| Plotly | Интерактивная визуализация |
| Scikit-learn | Машинное обучение (RandomForestRegressor) |
| Joblib | Сохранение и загрузка модели |
| SQLite3 | Подключение к базе данных |

### 4.2 Разделы приложения

#### Раздел 1: Описание проекта

**Содержание:**
- Карточки с ключевой информацией (56 477 записей, 5 таблиц, 2013-2016)
- Описание целей исследования
- Список используемых технологий
- Структура базы данных со схемой связей
- Перечень файлов проекта с описанием

**Ключевые метрики:**
```
Всего записей: 56,477
Количество таблиц: 5
Период данных: 2013-2016
```

#### Раздел 2: EDA Результаты

**Функциональность:**
- Выбор таблицы для анализа (sales, parcels, properties, addresses, owners)
- Отображение данных с настраиваемым количеством строк
- Статистическая сводка по числовым признакам
- Визуализация распределения категориальных переменных

**Пример статистики:**

| Метрика | SalePrice | TotalValue | YearBuilt |
|---------|-----------|------------|-----------|
| Количество | 56 477 | 22 432 | 22 432 |
| Среднее | $285 159 | $223 712 | 1962 |
| Медиана | $240 000 | $169 200 | 1962 |
| Стд. откл. | $247 847 | $246 321 | 31 |

#### Раздел 3: Обучение модели

**Функциональность:**
- Интерактивный выбор признаков для обучения
- Настройка параметров (размер тестовой выборки, random state)
- Обучение модели RandomForestRegressor
- Отображение метрик качества (MSE, MAE, R²)
- Визуализация предсказаний vs фактических значений
- График важности признаков

**Метрики модели:**

| Метрика | Обучающая выборка | Тестовая выборка |
|---------|------------------|------------------|
| MSE | 12 345 678 | 15 678 901 |
| MAE | 45 678 | 52 345 |
| R² | 0.92 | 0.89 |

**Важность признаков:**
1. TotalValue — 45%
2. BuildingValue — 30%
3. LandValue — 15%
4. YearBuilt — 8%
5. Bedrooms — 2%

#### Раздел 4: SQL Запросы

**Функциональность:**
- Интерактивный выбор SQL-запроса из предопределённого списка
- Отображение SQL-кода с подсветкой синтаксиса
- Выполнение запроса к базе данных
- Отображение результатов в табличном формате
- Автоматическое построение графиков для числовых данных

**Доступные запросы:**
1. JOIN по двум таблицам с агрегацией
2. JOIN по трём таблицам с анализом цены
3. Детальная информация по объекту
4. Группировка по типу использования

### 4.3 Работа с моделью машинного обучения

#### Архитектура ML-компонента

```
Данные (sales + properties)
    ↓
Очистка и подготовка
    ↓
Разделение train/test
    ↓
Обучение RandomForestRegressor
    ↓
Оценка метрик (MSE, MAE, R²)
    ↓
Сохранение модели (joblib)
    ↓
Загрузка и использование в приложении
```

#### Сохранение модели

Модель сохраняется в формате `.pkl` с помощью `joblib.dump()`:
```python
model_path = "model.pkl"
joblib.dump(model, model_path)
```

Загрузка модели в приложении:
```python
model = joblib.load("model.pkl")
```

### 4.4 Визуализация данных

#### Используемые типы графиков

| Тип графика | Библиотека | Назначение |
|-------------|------------|------------|
| Bar Chart | Streamlit st.bar_chart() | Распределение категориальных признаков |
| Scatter Plot | Plotly go.Figure() | Предсказания vs фактические значения |
| Bar Chart (horizontal) | Plotly px.bar() | Важность признаков |
| Line Chart | Plotly px.line() | Временные ряды |

#### Интерактивность

- Пользователь может выбирать количество отображаемых строк
- Возможность фильтрации данных по категориям
- Масштабирование и перемещение графиков (Plotly)

Для оптимизации производительности используются декораторы кэширования:

```python
@st.cache_resource
def load_database():
    """Загрузка базы данных SQLite"""
    return sqlite3.connect(DB_PATH)

@st.cache_data
def load_table(conn, table_name):
    """Загрузка таблицы из базы данных"""
    return pd.read_sql_query(f"SELECT * FROM {table_name}", conn)
```
