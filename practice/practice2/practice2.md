**Практическая работа 2**

**Тема: “**Проектная работа. Разработка веб-проекта для анализа данных. Библиотека Streamlit”.

**Формулировка задания**

Реализовать небольшой веб-сервис с функционалом витрины данных. Сервис предоставляет возможность просмотра результатов проведенного исследования.

В качестве исследования выбрать Практическую работу 1.

В окне браузера требуется отобразить: таблицы, графики, текстовые данные, полученные в ходе работы с данными.

Учесть, что проект будет расширяться для работы с машинным обучением.

Отобразить следующие разделы на одной или нескольких страницах приложения:

* Общее описание проекта;
* Основные результаты EDA (исследовательского анализа данных);
* Обучающая и тестовая выборка.

**Требования к проекту**

* Приложение реализовать с использованием библиотеки Streamlit или другой библиотеки по согласованию с наставником.
* В приложение включить, как минимум, одну страницу.
* Работу в приложении реализовать с выгруженной обученной моделью. Это может быть модель Классического машинного обучения с расширением pkl, модель задачи Компьютерного зрения или модель задачи Обработки естественного языка.
* В папку проекта добавить файл requirements.txt с перечислением всех библиотек проекта и их версий.
* В папку проекта добавить файл ReadMe.md с описанием приложения.

**Планируемый результат**

1. Архив с проектом, включающим все страницы проекта, описание проекта и данные проекта.
2. Ссылка на размещенный проект на одном из ресурсов: <https://github.com/>, <https://huggingface.co/>, Google Colab или аналогичные ресурсы
