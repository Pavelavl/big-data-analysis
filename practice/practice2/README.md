# Nashville Housing Analysis

Веб-приложение для визуализации результатов исследования данных недвижимости в Нэшвилле, штат Теннесси.

**Технологии:** Streamlit, Python, SQLite3, Scikit-learn

## 📋 Описание проекта

Данный веб-сервис предоставляет интерактивный интерфейс для просмотра результатов анализа данных Nashville Housing, включая:
- Просмотр структуры реляционной базы данных
- Исследовательский анализ данных (EDA)
- Обучение и оценку модели машинного обучения
- Выполнение сложных SQL-запросов с JOIN операциями

## 🚀 Установка и запуск

### Требования

- Python 3.10+
- pip

### Установка зависимостей

```bash
pip install -r requirements.txt
```

### Запуск приложения

```bash
streamlit run app.py
```

Приложение будет доступно по адресу: `http://localhost:8501`

## 🏛️ База данных

Приложение использует реляционную базу данных SQLite, созданную в Практической работе 1:

**Путь к БД:** `../practice1/nashville_relational.db`

**Структура базы:**
- `parcels` - участки земли (48,559 записей)
- `addresses` - адреса (50,638 записей)
- `properties` - характеристики недвижимости (22,432 записи)
- `owners` - владельцы (19,713 записей)
- `sales` - информация о продажах (56,477 записей)

## 🎯 Функционал приложения

### 1. Описание проекта
- Общая информация о проекте
- Структура базы данных
- Связи между таблицами

### 4. SQL Запросы
- Выполнение предопределённых SQL-запросов
- Просмотр SQL-кода

- Визуализация результатов

## 📊 Модель машинного обучения

**Тип задачи:** Регрессия

**Целевая переменная:** `SalePrice` - цена продажи недвижимости

**Признаки:**
- `LandValue` - стоимость земли
- `BuildingValue` - стоимость здания
- `TotalValue` - общая стоимость
- `YearBuilt` - год постройки
- `Bedrooms` - количество спален
- `FullBath` - количество полных ванных
- `HalfBath` - количество полуванных

**Алгоритм:** RandomForestRegressor (100 деревьев)

**Метрики качества:**
- MSE (Mean Squared Error)
- MAE (Mean Absolute Error)
- R² (Coefficient of Determination)
