# Nashville Housing AutoML

API и веб-интерфейс для автоматизированного машинного обучения с использованием PyCaret AutoML.

**Технологии:** FastAPI, Streamlit, PyCaret AutoML

## 📋 Описание проекта

Данный проект реализует серверную часть (FastAPI) и клиентскую часть (Streamlit) для:
- Автоматизированного машинного обучения с использованием PyCaret
- Сравнения результатов AutoML с ручным ML (RandomForest)
- Визуализации результатов обучения и сравнения

## 🚀 Установка и запуск

### Требования

- Python 3.10+
- pip

### Установка зависимостей

```bash
pip install -r requirements.txt
```

### Установка PyCaret (AutoML)

```bash
pip install pycaret[full]
```

### Запуск серверной части (FastAPI)

```bash
cd practice4
python main.py
```

API будет доступен по адресу: `http://localhost:8000`

### Запуск клиентской части (Streamlit)

```bash
cd practice4
streamlit run app.py
```

Приложение будет доступно по адресу: `http://localhost:8501`

**Примечание:** Сервер должен быть запущен перед запуском клиента!

## 📊 Функционал Streamlit приложения

### 1. Данные и статистика
- Загрузка данных из API
- Просмотр структуры данных
- Статистика по числовым столбцам
- Корреляционная матрица

### 2. Настройка обучения
- Выбор целевой переменной (по умолчанию: SalePrice)
- Выбор признаков для обучения
- Настройка параметров:
  - Размер тестовой выборки (10-40%)
  - Random State
  - Количество деревьев для Manual ML
  - Метрика качества для AutoML (R², MAE, MSE, RMSE)
  - Время обучения (60-600 сек)
  - Количество фолдов для CV (3-10)

### 3. Обучение моделей
- **Manual ML (RandomForest):**
  - Быстрое обучение на одном алгоритме
  - 100 деревьев, настроенные параметры
  - Полный контроль над процессом

- **AutoML (PyCaret):**
  - Автоматический выбор лучшего алгоритма
  - Сравнение множества моделей:
    - Linear Regression
    - Ridge
    - Lasso
    - Elastic Net
    - K-Nearest Neighbors
    - Decision Tree
    - Random Forest
    - XGBoost
    - LightGBM
  - Автоматическая настройка гиперпараметров
  - Кросс-валидация для оценки качества

### 4. Результаты обучения
- **Для Manual ML:**
  - Алгоритм (RandomForestRegressor)
  - Метрики качества (R², MSE, MAE, RMSE)
  - Время обучения
  - Важность признаков
  - Сохранение модели

- **Для AutoML:**
  - Лучшая модель (автоматический выбор)
  - Алгоритм лучшей модели
  - Метрики качества
  - Время обучения
  - Важность признаков
  - Сохранение модели
  - Сравнение всех моделей AutoML (таблица)

### 5. Сравнение Manual vs AutoML
- Графическое сравнение R² Score
- Сравнение времени обучения
- Определение победителя (метод с лучшим R²)
- Улучшение в процентах
- Сравнение важности признаков

## 🚧 Архитектурные особенности

- **Разделение клиента и сервера:** Streamlit (UI) + FastAPI (API)
- **Автоматизация:** PyCaret автоматически выбирает и настраивает модели
- **Сравнение:** Возможность сравнить AutoML с ручным методами
- **Сохранение моделей:** Все модели сохраняются в формате .pkl
- **Фоновое обучение:** AutoML работает в фоновом режиме
- **REST API:** Полный REST API для интеграции с другими системами

## 📈 Примеры использования

### Запуск API сервера
```bash
python main.py
```

### Запуск Streamlit клиента
```bash
streamlit run app.py
```

### API запросы

```bash
# Получить данные
curl http://localhost:8000/ml/data

# Обучить модель вручную
curl -X POST http://localhost:8000/ml/train/manual \
  -H "Content-Type: application/json" \
  -d '{
    "target": "SalePrice",
    "features": ["LandValue", "BuildingValue", "TotalValue"],
    "test_size": 0.2,
    "random_state": 42,
    "n_estimators": 100
  }'

# Обучить модель с AutoML
curl -X POST http://localhost:8000/ml/train/automl \
  -H "Content-Type: application/json" \
  -d '{
    "target": "SalePrice",
    "features": ["LandValue", "BuildingValue", "TotalValue"],
    "test_size": 0.2,
    "metric": "r2",
    "time_limit": 300,
    "n_folds": 5
  }'

# Сравнить результаты
curl http://localhost:8000/ml/compare

# Список моделей
curl http://localhost:8000/models
```
