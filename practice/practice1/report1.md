## 4. Описание проделанной работы

### 4.1 Создание реляционной базы данных

Из CSV-файла Nashville Housing (56 477 записей) создана реляционная база данных SQLite3 с нормализованной структурой из 5 таблиц.

#### Структура базы данных

| Таблица | Описание | Записей | Первичный ключ |
|---------|----------|---------|----------------|
| `parcels` | Участки земли | 48 559 | ParcelID |
| `addresses` | Адреса объектов | 50 638 | AddressID |
| `properties` | Характеристики недвижимости | 22 432 | PropertyID |
| `owners` | Владельцы | 19 713 | OwnerID |
| `sales` | Информация о продажах | 56 477 | SaleID |

#### Связи между таблицами

```
parcels (1) ── (1) properties
parcels (1) ── (N) addresses
parcels (1) ── (N) sales ── (N) owners
```

### 4.3 Работа с pandas

Выполнены аналогичные запросы с использованием библиотеки pandas для загрузки данных из SQLite3 и выполнения операций аналогичных SQL-запросам.

**Ключевые возможности:**
- `read_sql_query()` — загрузка данных из БД в DataFrame
- `merge()` — аналог JOIN
- `groupby()` + `agg()` — группировка и агрегация
- Фильтрация через булевы выражения

### 4.4 Работа с pySpark

Фреймворк pySpark настроен с переменными окружения `JAVA_HOME` и `SPARK_HOME`. Выполнены запросы аналогичные задаче 1 с использованием PySpark DataFrame API.

**Ключевые возможности:**
- `SparkSession.builder.createSession()` — создание сессии
- `read.jdbc()` или `read.format('jdbc')` — загрузка данных
- `join()` — соединение таблиц
- `groupBy()` + `agg()` — агрегация
- `orderBy()` — сортировка
