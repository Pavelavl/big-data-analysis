### 5. Алгоритм: Линейная регрессия

#### Описание алгоритма

Линейная регрессия — метод машинного обучения с учителем для прогнозирования непрерывной целевой переменной. Модель строит линейную зависимость между входными признаками и целевой переменной:

```
y = β₀ + β₁x₁ + β₂x₂ + ... + βₙxₙ + ε
```

где:
- y — целевая переменная
- β₀ — свободный член (intercept)
- β₁...βₙ — коэффициенты регрессии
- x₁...xₙ — входные признаки
- ε — ошибка

#### Преимущества линейной регрессии:
- Простота и интерпретируемость
- Высокая скорость обучения
- Коэффициенты показывают влияние каждого признака
- Хорошо работает с линейно зависимыми данными

### 9. Ответы на контрольные вопросы

1. **Что такое регрессионный анализ?**
   Регрессионный анализ — это статистический метод для исследования зависимости одной переменной от одной или нескольких независимых переменных. Цель регрессии — построить модель, которая предсказывает значения зависимой переменной на основе значений независимых переменных.

2. **Какую задачу решает линейная регрессия?**
   Линейная регрессия решает задачу прогнозирования непрерывной целевой переменной путем построения линейной зависимости между входными признаками и целевой переменной.

3. **Какие преимущества имеет линейная регрессия?**
   - Простота и интерпретируемость
   - Высокая скорость обучения
   - Коэффициенты показывают влияние каждого признака
   - Хорошо работает с линейно зависимыми данными

4. **Какое существует общее уравнение для линейной регрессии для двумерного пространства?**
   y = β₀ + β₁x + ε
   где y — целевая переменная, x — признак, β₀ — intercept, β₁ — наклон, ε — ошибка.

5. **Какие входные и выходные параметры используются в модели множественной линейной регрессии?**
   Входные: матрица признаков X (n×m), где n — количество образцов, m — количество признаков
   Выходные: вектор предсказанных значений ŷ (n×1)

6. **Как работает алгоритм k-ближайших соседей для регрессии? В чем отличие работы от классификации?**
   KNN для регрессии предсказывает значение как среднее (или взвешенное среднее) целевых значений k ближайших соседей в пространстве признаков. Отличие от классификации: в регрессии предсказывается непрерывное значение (среднее соседей), а в классификации — категория (голосование большинства).

7. **Чем отличается LASSO от линейной регрессии?**
   LASSO (L1-регуляризация) добавляет штраф на сумму абсолютных значений коэффициентов к функции потерь. Это приводит к занулению некоторых коэффициентов, тем самым выполняя отбор признаков.

8. **Чем отличается ElasticNET от линейной регрессии?**
   ElasticNET комбинирует L1 (LASSO) и L2 (Ridge) регуляризации, добавляя штраф как на сумму абсолютных значений, так и на сумму квадратов коэффициентов. Это позволяет сочетать преимущества обоих методов.

9. **Какие метрики оценки качества алгоритмов регрессии Вы рассчитали в задании? По какой формуле они рассчитываются?**
   Рассчитаны следующие метрики:
   - **MAE** = (1/n) × Σ|yᵢ - ŷᵢ| — средняя абсолютная ошибка
   - **MSE** = (1/n) × Σ(yᵢ - ŷᵢ)² — среднеквадратическая ошибка
   - **RMSE** = √MSE — корень из MSE
   - **MAPE** = (100/n) × Σ|(yᵢ - ŷᵢ) / yᵢ| — средняя абсолютная процентная ошибка
   - **R²** = 1 - [Σ(yᵢ - ŷᵢ)² / Σ(yᵢ - ȳ)²] — коэффициент детерминации

10. **Что означает операция нормализации признаков, и чем она отличается от операции стандартизации?**
    **Нормализация** (MinMaxScaler) приводит признаки к диапазону [0, 1]:
    ```
    x_norm = (x - x_min) / (x_max - x_min)
    ```
    **Стандартизация** (StandardScaler) приводит признаки к среднему 0 и стандартному отклонению 1:
    ```
    x_std = (x - x_mean) / x_std
    ```
    Стандартизация сохраняет распределение данных и устойчива к выбросам, нормализация сжимает все данные в фиксированный диапазон.
