### 4. Метод: PCA (Principal Component Analysis)

#### Описание метода

PCA — метод главных компонент — это линейный метод снижения размерности, который преобразует данные в новую систему координат, где оси (главные компоненты) ортогональны и упорядочены по уменьшению дисперсии.

**Принцип работы:**
1. Центрирование данных
2. Вычисление ковариационной матрицы
3. Вычисление собственных векторов и собственных значений
4. Выбор k главных компонент с наибольшей дисперсией

#### Объясненная дисперсия

### 7. Метод: KMeans Clustering

#### Описание метода

KMeans (k-средних) — алгоритм кластеризации, который разбивает n объектов на k кластеров таким образом, чтобы минимизировать сумму квадратов расстояний от каждой точки до центроида её кластера.

**Принцип работы:**
1. Инициализация k центроидов (случайно или k-means++)
2. Назначение каждой точки ближайшему центроиду
3. Пересчет центроидов как среднее значений точек кластера
4. Повторение шагов 2-3 до сходимости

#### Определение оптимального числа кластеров

**Метод локтя:**
- Оптимальное k = 5 (по графику инерции)

**Метод силуэта:**
- Оптимальное k = 2 (максимальный score = 0.681)

Для данного анализа использовано k=3 (известное истинное число классов).

### 9. Ответы на контрольные вопросы

1. **Для чего предназначен метод главных компонент и какова его основная идея?**
   PCA предназначен для снижения размерности данных. Основная идея — найти новые ортогональные переменные (главные компоненты), которые максимизируют дисперсию данных и позволяют представить данные с минимальной потерей информации.

2. **Какие основные различия между линейными и нелинейными методами снижения размерности?**
   Линейные методы (PCA, LDA) предполагают линейную структуру данных. Нелинейные методы (t-SNE, UMAP) могут захватывать сложные нелинейные зависимости и работают лучше на сложных структурах данных.

3. **Сравните методы PCA, t-SNE и UMAP. Какой из них более универсальный?**
   - **PCA:** быстрый, линейный, хорош для визуализации глобальной структуры
   - **t-SNE:** медленный, нелинейный, хорошо показывает локальную структуру
   - **UMAP:** быстрый, нелинейный, сохраняет и глобальную, и локальную структуру. **UMAP наиболее универсальный.**

4. **Чем специфичны задачи обучения без учителя?**
   В обучении без учителя нет размеченных целевых переменных. Задача заключается в поиске скрытых структур, паттернов или группировок в данных (кластеризация, снижение размерности, обнаружение аномалий).

5. **Как можно оценить качество кластеризации?**
   - Внутренние метрики: Silhouette Score, Davies-Bouldin Index, Calinski-Harabasz Index
   - Внешние метрики (при наличии истинных меток): ARI, AMI, Homogeneity, Completeness, V-measure

6. **Какова постановка задачи кластеризации?**
   Разбиение множества объектов на непересекающиеся группы (кластеры) так, чтобы объекты внутри кластера были максимально похожи, а объекты из разных кластеров — максимально различны.

7. **Какое основное отличие между иерархической и неиерархической кластеризацией?**
   Иерархическая кластеризация строит дерево вложенных кластеров (дендрограмму), не требует заранее заданного числа кластеров. Неиерархическая кластеризация (KMeans) сразу разбивает данные на заданное число кластеров.

8. **Если мы хотим кластеризовывать кольцевидные элементы какие алгоритмы лучше всего подойдут?**
   Алгоритмы, способные захватывать нелинейные структуры: DBSCAN, Spectral Clustering, Gaussian Mixture Models.

9. **Какой процент остаточной дисперсии нужно выбрать для выбора n-ого количества главных компонент? На чём основывается этот выбор?**
   Обычно выбирают 90-95% объясненной дисперсии. Выбор основывается на графике кумулятивной дисперсии — ищут "плечо" (elbow), после которого добавление новых компонент дает малый прирост объясненной дисперсии.

10. **Какова основная идея алгоритма KMeans?**
    Итеративно минимизировать сумму квадратов расстояний от точек до центроидов их кластеров, обновляя центроиды как среднее значение точек в кластере.

11. **Какова основная идея агломеративного алгоритма?**
    Агломеративная иерархическая кластеризация начинается с того, что каждая точка — отдельный кластер, затем последовательно объединяет ближайшие кластеры до тех пор, пока не останется один кластер.

12. **Как оценить качество кластеризации?**
    См. вопрос 5 — использовать Silhouette Score, ARI, AMI и другие метрики.

13. **Чем отличается метод локтя от метода силуэта?**
    **Метод локтя:** анализирует график зависимости инерции от числа кластеров, ищет точку резкого замедления уменьшения инерции.
    **Метод силуэта:** для каждого числа кластеров вычисляет средний силуэт, который измеряет, насколько хорошо объект принадлежит своему кластеру по сравнению с другими.

14. **Метод оценки кластеризации по формуле более универсален или нет? В чем он состоит?**
    Silhouette Score более универсален, так как не требует истинных меток и работает для любого числа кластеров. Формула:
    ```
    s(i) = (b(i) - a(i)) / max(a(i), b(i))
    ```
    где a(i) — среднее расстояние до объектов своего кластера, b(i) — среднее расстояние до объектов ближайшего соседнего кластера.
